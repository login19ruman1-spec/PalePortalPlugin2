# PalePortal

Плагин для **Paper 1.21.4** (Java 21): портал в измерение «Бледный лес» (Pale Garden)
через существующую рамку из `reinforced_deepslate` в древнем городе, активируемый
мелодией на музыкальных блоках. Включает кастомный генератор мира и 4 вида
скрипунов (Creaking).

## Структура проекта

```
PalePortal/
├── pom.xml
├── README.md
└── src/main/
    ├── java/com/paleportal/
    │   ├── PalePortalPlugin.java   - главный класс, мир pale_forest, правила мира
    │   ├── ConfigManager.java      - config.yml
    │   ├── DataManager.java        - data.yml (состояние портала между рестартами)
    │   ├── PortalManager.java      - геометрия рамки, частицы, слом/восстановление, телепорт
    │   ├── NoteListener.java       - распознавание мелодии на нодблоках
    │   ├── CreakingManager.java    - 4 вида скрипунов
    │   ├── PaleWorldGenerator.java - генератор мира "Бледный лес"
    │   └── PalePortalCommand.java  - команда /paleportal (алиас /paleporatl)
    └── resources/
        ├── plugin.yml
        └── config.yml
```

## 1. Сборка

Нужны **JDK 21** и **Maven 3.9+**.

```bash
cd PalePortal
mvn clean package
```

Готовый jar появится в `target/PalePortal-1.0.0.jar`.

> Сборка один раз скачивает `paper-api` с `repo.papermc.io` (прописано в `pom.xml`),
> поэтому первой сборке нужен доступ в интернет.

## 2. Установка на сервер

1. Скопируйте `target/PalePortal-1.0.0.jar` в папку `plugins/` вашего Paper 1.21.4 сервера.
2. Запустите сервер один раз, чтобы плагин создал `plugins/PalePortal/config.yml` и `data.yml`.
3. Остановите сервер (или используйте `/paleportal reload` после правки конфига).

## 3. Настройка координат

### 3.1. Рамка древнего города

В `config.yml` укажите любые два противоположных угла уже сгенерированной рамки
из `reinforced_deepslate` (плагин сам вычислит минимальные/максимальные координаты
и внутреннюю зону 2×3):

```yaml
portal-frame:
  corner1: { x: ..., y: ..., z: ... }
  corner2: { x: ..., y: ..., z: ... }
```

Проще всего это сделать в игре:

1. Встаньте в первом углу рамки → `/paleportal setportal`
2. Встаньте в противоположном углу рамки → `/paleportal setportal` ещё раз

Плагин сам определит толщину рамки (ось, где обе координаты совпадают) и покажет
внутри неё блоки портала (`LIGHT_BLUE_STAINED_GLASS` по умолчанию, меняется в
`portal-glass-material`).

**Важно:** плагин не создаёт и не трогает блоки самой рамки — они должны быть
настоящим `reinforced_deepslate`, сгенерированным структурой древнего города.
Если игрок сломает хотя бы один блок рамки, блоки портала исчезнут; если рамку
восстановить - портал появится снова.

### 3.2. Музыкальные блоки (5 штук)

Расставьте 5 музыкальных блоков (`NOTE_BLOCK`) перед порталом, в радиусе
`music-radius` (по умолчанию 10) блоков от центра рамки. Порядок важен — это и
есть порядок нот мелодии.

В игре: встаньте у первого блока → `/paleportal setmusic`, у второго → снова
`/paleportal setmusic`, и так для всех пяти. Команда скажет, если блок вышел
за пределы допустимого радиуса.

Мелодия по умолчанию (ID нот 0-24): `F# A C# A F#` → `6 10 13 10 6`, настраивается
в `melody:` в `config.yml`. Играется правым кликом по нодблокам (меняет ноту и
тут же её проигрывает) — ровно в указанном порядке, каждая нота на своём блоке,
в течение `melody-time-limit-seconds` (по умолчанию 30 секунд).

### 3.3. Точка входа в «Бледный лес»

```yaml
pale-forest:
  world-name: pale_forest
  entry: { x: ..., y: ..., z: ..., yaw: 0, pitch: 0 }
```

Мир `pale_forest` создаётся автоматически при первом запуске плагина (если ещё
не существует) с собственным генератором ландшафта. При последующих запусках
мир не пересоздаётся — используется существующий.

## 4. Команды

| Команда | Описание | Права |
|---|---|---|
| `/paleportal reload` | Перезагрузить `config.yml` | OP |
| `/paleportal spawn <normal\|smart\|kind\|ancient>` | Заспавнить скрипуна в точке игрока | OP |
| `/paleportal setportal` | Установить угол рамки по позиции игрока (вызвать 2 раза) | OP |
| `/paleportal setmusic` | Установить следующий музыкальный блок по позиции игрока (вызвать 5 раз) | OP |

Алиасы команды: `/paleporatl`, `/pp`.

## 5. Поведение скрипунов

| Вид | Поведение | Урон | Здоровье |
|---|---|---|---|
| Обычный | Ванильное (атакует, когда на него не смотрят) | 4 | 20 |
| Умный | Атакует всегда, независимо от взгляда игрока | 8 | 30 |
| Добрый | Не атакует первым, отвечает 10 сек после полученного урона | 0 | 15 |
| Древний (босс) | Атакует всех в радиусе `aggro-radius`, медленный (`speed: 0.15`) | 6 | 50 |

Все характеристики настраиваются в `config.yml` → `creakings:`.

> Полная замена вшитого ванильного ИИ Creaking (стоп-кадр под взглядом игрока)
> требует доступа к Brain/Goal-селектору моба на уровне NMS. Чтобы остаться
> строго в рамках публичного Paper API, виды «умный»/«добрый»/«древний»
> управляются через лёгкий повторяющийся таск (`Mob#setTarget`), что даёт
> нужное игровое поведение (кто и когда атакует, с какой силой), но не отменяет
> низкоуровневую анимацию "замирания" ванильного Creaking при прямом взгляде.
> Урон, здоровье, частицы, звук и спавн реализованы через стандартные события
> Paper API без единой строчки NMS.

Автоспавн (по умолчанию каждые 5 минут) создаёт случайного скрипуна в радиусе
`spawn-radius` от точки входа в `pale_forest`, не ближе `min-distance-to-player`
к игрокам, пока общее число заспавненных плагином скрипунов меньше `max-alive`.

## 6. Что сохраняется между рестартами (`data.yml`)

- `portal-active` — цела ли рамка прямо сейчас (есть ли блоки портала);
- `teleport-unlocked` — была ли уже успешно сыграна мелодия (повторно играть не нужно);
- `world-generated` — создавался ли уже мир `pale_forest` этим плагином.

## 7. Как залить в GitHub

Содержимое этого zip-архива — это и есть корень репозитория. Просто распакуйте
архив в пустую папку и инициализируйте в ней git:

```bash
git init
git add .
git commit -m "PalePortal: initial import"
git branch -M main
git remote add origin https://github.com/<ваш-аккаунт>/<репозиторий>.git
git push -u origin main
```

`.gitignore` уже исключает `target/` и файлы IDE.
